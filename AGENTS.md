# Documentation requirements

- Before proposing, implementing, debugging, or reviewing Nuxt-related code, use the configured Nuxt MCP tools (server: `nuxt`; endpoint: https://nuxt.com/mcp).
- Before doing any UI-related work, use the configured Nuxt UI MCP tools (server: `nuxt_ui`; endpoint: https://ui.nuxt.com/mcp).
- Discover the relevant configured MCP tools before using the documentation fallback; deferred tools may require tool search. Server names may differ between clients; identify the relevant server by its purpose and endpoint.
- If the relevant MCP tools are unavailable in the current session or a lookup fails, read https://nuxt.com/llms.txt for Nuxt or https://ui.nuxt.com/llms.txt for Nuxt UI, and follow the relevant documentation links.
- Consult documentation relevant to the task and the project's installed versions. Apply both requirements when the work involves Nuxt and UI.
